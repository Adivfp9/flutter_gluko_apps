GlukoTrack membantu Anda mencatat dan memantau gula darah puasa maupun sewaktu. Aplikasi ini bukan alat diagnosis.

Target dan status di aplikasi bersifat umum. Sesuaikan target pribadi bersama dokter.
Data tersimpan hanya di perangkat ini, terenkripsi, tanpa akun.
Bila gula darah sangat rendah atau sangat tinggi, segera cari pertolongan medis.
